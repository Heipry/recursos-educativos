# Portfolio de Recursos Formativos

![Portada del proyecto](images/home.jpg)

## 📋 Descripción

Portfolio web personal que recopila recursos educativos, proyectos finalizados y herramientas formativas desarrolladas a lo largo de mi carrera como docente y consultor web. El proyecto incluye múltiples secciones con ejemplos de código, laboratorios frontend, tests interactivos y material didáctico.

## 🎯 Características principales

- **Proyectos Finalizados**: Soluciones reales desplegadas en producción 
- **Laboratorio Frontend**: Efectos CSS/JS y ejemplos de código para clase
- **Fragmentos de código**: Gists y recursos educativos en GitHub
- **Tests y Autoevaluaciones**: Ejercicios interactivos de CSS, JavaScript y Linux
- **Material multimedia**: Videos de formación y streaming

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3 (con efectos avanzados y animaciones)
- JavaScript (VanillaJS y jQuery)
- Bootstrap 3
- Font Awesome
- Responsive Design
- Git & GitHub
